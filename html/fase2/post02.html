> Enviando a Contribuição



GitLab

Configurar o GitLab para poder contribuir com o Gnome é um pouco chato. Primeiro, criamos a conta no GitLab normalmente. Depois, criamos uma conta no GitLab Gnome. Agora, para evitar criar uma nova chave SSH (para ser um pouco mais rápido), ativamos a vericação em duas etapas na conta e criamos um token de acesso. Com esse token, podemos fazer git push. Agora, ainda no GitLab, fazemos um fork do calendário e o adicionamos como repositório remoto.


Merge Request

Enviar a contribuição é um processo simples: criamos uma nova branch usando git checkout -b hide-calendar-selection, fazemos um commit para essa branch e depois um push para o repositório remoto. No terminal, recebemos um link para criação da merge request. Basta seguir as intruções e a MR está feita🔗.
